# SOC Analyst Journey

A structured 4-week bootcamp documenting my path from CCNA-certified network engineer to SOC Analyst readiness. This repository contains notes, lab reports, scripts, PCAP analyses, and investigation write-ups.

## About Me

- CCNA Certified (200-301)
- Linux experience (Kali, Ubuntu)
- Bash scripting (project-based)
- Python (OOP, basic ML)
- Currently building practical SOC skills

## Roadmap

| Week | Focus Area | Key Topics | Status |
|------|-----------|------------|--------|
| 1 | Networking for SOC | TCP/IP, DNS, HTTP, Routing, Firewalls, Wireshark | In Progress |
| 2 | OS and Security Fundamentals | Linux Internals, Windows Logs, Permissions, Malware, MITRE ATT&CK | Not Started |
| 3 | SIEM and Threat Detection | Splunk, Log Analysis, Detection Rules, Phishing, Brute Force | Not Started |
| 4 | Incident Response and Capstone | IR Lifecycle, Alert Triage, PCAP Investigation, Final Report | Not Started |

## Repository Structure

Each week contains:
- `notes/` — Concept explanations and study material
- `labs/` — Hands-on lab documentation with steps and findings
- `scripts/` — Bash and Python automation scripts (Week 2 onward)
- `screenshots/` — Evidence and output captures

## Tools Used

- Wireshark (Packet Analysis)
- Nmap (Network Scanning)
- Splunk Free (SIEM)
- Kali Linux (Security Testing)
- Cisco Packet Tracer (Network Simulation)
- Python / Bash (Automation)
- tcpdump (CLI Packet Capture)

## How to Navigate

Start from `week-1-networking/README.md` and follow the daily progression. Each lab includes objectives, topology, steps taken, findings, and lessons learned.

## Goal

To build a documented, practical skill set sufficient for a SOC Analyst L1 role, with emphasis on network-based threat detection, log analysis, and incident investigation
